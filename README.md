# 🩸 Life Link Blood Donor

A modern blood donor management and emergency blood request platform that helps connect blood donors with patients in need quickly and efficiently.

## 🌐 Live Demo

🚀 Live Website: https://life-link-blood-donor.lovable.app/register

---

# 📌 About The Project

Life Link Blood Donor is a web-based platform designed to simplify the process of finding blood donors during emergencies. The platform allows users to:

- Register as blood donors
- Search donors by blood group
- Submit emergency blood requests
- Connect donors and recipients instantly
- Maintain donor availability records
- Improve emergency healthcare support

The main goal of this project is to create a fast, reliable, and user-friendly blood donation network that can help save lives.

# ⚙️ Installation

## Clone the Repository

```bash
git clone https://github.com/your-username/life-link-blood-donor.git
```

## Navigate to Project Directory

```bash
cd life-link-blood-donor
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```
